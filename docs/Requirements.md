# Agreed v1 requirements

1. Edit wall and product dimensions, heights, alignments, gaps, panel margins and depth preferences. Retain measured facts, design preferences, derived values, sources and uncertainty separately.
2. Recognizable finished rendering of TV, media console, fluted wall and soundbar using shared scale and product-informed materials and silhouettes.
3. Fixed front, side and angled view buttons. No freeform orbit, camera movement or drag placement.
4. Previous/next inspection controls reveal behind TV, behind feature panel, behind slats and inside wall. Preserve inspection level when changing angle. Include studs, blocking, spacers and electrical schematic geometry with uncertainty clearly indicated.
5. Lightly visible dimensions; hover/focus emphasizes lines/endpoints and magnifies labels without shifting layout.
6. Adjacent annotation edit buttons open a distances drawer, reveal and select the relevant input. Focused inputs highlight their corresponding dimension. Derived dimensions identify their controlling inputs.
7. Immediate coherent updates across views, basic clearance/overlap findings and local save/load/reset.
8. Parameterized reusable React presentation, vanilla controllers/stores, pure geometry, PascalCase TS/TSX filenames. No root god component or business rules in React effects.

## Milestones

1. Foundation: scaffold, local Git, products/project/spatial model, controller/store, diagnostic interface and depth tests.
2. Finished front view: product appearance and scaled composition.
3. Dimension annotations and editing drawer.
4. Preset angles and layer inspection.
5. Persistence, integration polish, keyboard behavior and clearance findings.

Pause to align interfaces and review the working result at each milestone. Remote setup and pushes to the personal repository are authorized, with deployment to GitHub Pages. Vendor/product names, model identifiers, shopping links and prices belong only in ignored `.tmp/` artifacts; tracked code and documentation use generic part labels.
