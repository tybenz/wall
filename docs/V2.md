# V2 construction planning

V1 and v1.5 are complete. V2 turns the visual editor into a tool for checking how the assembly fits and operates in the room.

## Implemented first slice: mount positions

- Four fixed presets: Parked, Extended, Swivel left and Swivel right. Camera and inspection depth remain independent.
- TV, soundbar, cradle and TV-side mount rails share one rigid transform. Panel, wall plate, blocking and electrical stay fixed.
- Additional extension and swivel angle are editable in Structure and persist with the project. The selected preview position is session state. Earlier saves load with explicit provisional defaults of 18 inches extra extension and 30 degrees each side.
- Pose-aware drawings, dimension endpoints, camera fit, panel-plane clearance and vertical distance above console top.
- Selected-position collision checks use oriented boxes, including individual cradle members, against panel, wall finish, drywall, console and beam; they also report an assembly extending beyond the modeled wall width.

`MountMotion` is pure geometry. `resolveMountPreview(project, parkedAssembly, preset)` returns a transform, posed envelopes, schematic arm segments and findings without mutating the parked model. Renderers and annotations consume that result. `MotionGroup` applies the same transform to all attached drawings. React does not own motion rules.

The mount drawing uses four hinged arms forming a diamond between the fixed and moving plates. Its arm length is inferred for illustration, not a measured model. The user explicitly deferred extension/swivel coupling and joint-level simulation because these are not needed for build planning. Extension and angular limits remain unverified preferences. Collision checks evaluate the four selected positions, not the continuous movement between them. Panel-plane and console-top distances are signed reference-plane clearances, not minimum distances between arbitrary surfaces. The ceiling/beam collision envelopes remain conservative boxes.

## Hands-on checks

1. In Finished/Isometric, cycle through all four mount presets. TV, bar and cradle should stay together; the flat panel and cabinet stay put.
2. In Side and Behind TV, check the arm between the fixed wall plate and moving rails. Change camera or inspection depth and return; the chosen mount position stays selected.
3. Choose Swivel right, open Edit mount range, and reduce extension to zero. Clearance should become negative and collision findings should appear. Restore 18 inches; the initial 30-degree pose should clear the panel.
4. Edit swivel angle, gap and part dimensions. Pose-specific width/gap/cradle dimensions must stay attached to the rotated drawing. Parked returns the normal layout dimensions.
5. Save/export and reload/import edited motion limits. The saved design retains the limits; a new session starts at Parked.

## Construction planning

The user clarified that v2 should help plan construction inside and attached to the wall. External TV/console lead lengths, service slack and bend allowances have been removed. They are not part of this tool's scope.

- **Construction details** switches from the assembly preview to four fixed drawings: framing elevation, mount lag section, upper electrical section and panel edge section. Section cuts use the shared resolved assembly, not separate illustrative geometry. The framing elevation retains the vaulted wall outline.
- Editable stud face width, blocking depth, lag row spacing and proposed embedment replace hard-coded construction assumptions. Spacers bear directly on drywall and occupy cutouts in the slatted finish.
- Separate electrical plate and box/rough-opening envelopes. Plates remain centered below the mount with the specified gap; their width/height and the opening width/height/cavity depth are editable. Box bodies extend to the finished surface, and rough openings interrupt the slats and upper panel. The combined envelopes do not resolve separate power/signal compartments or box hardware.
- Independent proposed in-wall power and signal route offsets plus a route depth plane. Routes flag intersections with studs/blocking and depths beyond the cavity or box backs; these findings indicate unresolved passages, not automatically drilled holes.
- Dimension schedules show floor heights, wall offsets and layer thicknesses. Arrow buttons focus matching inputs in the existing drawer. Earlier saves receive explicit provisional defaults, preserving customized inputs. Retired external-cable fields are discarded if present in a project file.

## Named layout alternatives

Save up to 12 named complete project snapshots in a separate browser-local library. Compare the current layout with a selected saved layout, apply that snapshot, or update it from the current project. Comparison covers editable dimensions, confirmation flags, stud locations, part sizes/finishes, soundbar orientation and swivel angle; source notes are retained in each snapshot. A duplicate name requires an explicit update. Corrupt libraries and failed writes do not erase existing saved data. Single-project JSON export/import remains unchanged and does not include this library.

## Construction export

Export a standalone SVG sheet from Construction details. It contains all four fixed drawings, dimensional schedules in the selected units, current findings, and unresolved measurement / source-assumption notes. All text is XML-escaped. It is a vector study with model dimensions, not a print-scale fabrication drawing. Actual hardware, electrical compartments, framing passages and mount hole locations still need measured inputs.

## Hands-on construction checks

1. Open Construction details and cycle through all four views. Framing shows studs, blocking, plates, proposed lag crosses and two in-wall routes; sections expose the appropriate physical stack.
2. In Mount section, edit proposed lag embedment to 4 inches. The dashed paths and path dimension change, and findings report insufficient blocking depth. Restore 1.75 inches.
3. In Electrical section, edit box depth, plate dimensions and rough-opening dimensions independently. Check that the plate stays at the panel face and the 2-inch mount gap is preserved. A box deeper than the cavity or an opening larger than its plate should produce findings.
4. In Framing elevation, move a route horizontally through a stud. Its path changes and a framing-passage finding appears. Move it back into its bay.
5. Save a named alternative, change box depth or blocking height, and inspect the current/saved comparison. Apply the saved layout to restore all its project inputs.
6. Export the construction sheet and inspect the four views and unresolved notes. Switch display units and export again; physical geometry should be unchanged.

## Planned: distinguish design choices from physical facts

This is a future UX/model milestone, not implemented behavior. The tool must distinguish what the user is choosing from what the real wall or selected hardware dictates.

- **Design choices:** TV height, panel cut size, desired gaps, plate placement and proposed blocking layout. These belong in the normal exploration controls, with sliders and exact entry.
- **Physical facts:** measured wall/stud geometry and the dimensions of selected parts, such as electrical boxes, plates, panel stock and soundbar shelf material. Present these as reference dimensions, with a deliberate edit/verify action rather than exploratory sliders. They can be corrected or changed when selecting different hardware/material; they are not immutable application constants.
- **Unverified physical facts:** placeholders for an actual dimension remain visibly unverified facts. An unknown shelf thickness or box size must not become a design preference simply because it is currently adjustable. Retain the estimate, its source and the measurement still needed. Keep physical-fact verification separate from approving a design choice.
- **Derived values:** calculated heights, clearances, spacer depths and layer totals are read-only results, with access to their controlling inputs.

Choose a part/material separately from editing its factual dimensions. For example, selecting different shelf stock is a design choice; the thickness of that selected stock is a physical fact. Electrical box body, plate and required opening are distinct dimensions and should retain their respective sources.

Make the distinction consistent in drawer controls, drawing annotations, comparisons and exports. Normal layout alternatives should vary choices against a shared baseline of physical facts; applying an alternative must not silently undo a newly verified site measurement. Deliberate hardware/material alternatives should identify what part changed. The current complete-project snapshot implementation will need to evolve to honor that rule.

Audit the existing field classifications before implementation. The current model already records measurement/preference and provisional/confirmed metadata, but the UI treats fields similarly and some placeholders (including cradle thickness) are classified as preferences. Metadata alone does not fulfill this requirement.

## Further refinement

Replace provisional construction envelopes, box details, mount holes and cradle dimensions as actual measurements become available. Full linkage simulation remains deferred. External cable budgeting is intentionally excluded.
